# Пример: анализ

**Тема:** реакция рынка на запуск нового продукта.

**Главный вопрос:** можно ли считать устойчивое ценовое плато после запуска продукта признаком предопределенного спроса?

Skill определит задачу как **Анализ** и не станет сразу отвечать на вопрос. Сначала он предложит Блок 1 с темой, главным вопросом и целью анализа. После правки пользователя блок фиксируется. Затем по очереди согласуются контекст и данные, границы анализа, критерии сильного анализа и формат результата.

Только после подтверждения всех пяти блоков skill собирает итоговый промпт для reasoning-модели.
