# Пример: выбор

**Тема:** выбор ИИ-инструмента для PR-команды.

**Главный вопрос:** какой инструмент выбрать для регулярного анализа больших массивов публикаций при ограниченном бюджете?

Skill определит задачу как **Выбор**. Затем по одному согласует: вопрос и цель выбора, исходные данные, ограничения и приоритеты, критерии выбора и формат результата.

Если обнаружится существенная альтернатива, которой нет среди исходных вариантов, skill сначала предложит добавить ее пользователю, а не включит автоматически.
