# Deep Think Prompt Builder

Пошаговый конструктор промптов для задач, где модели требуется глубокое рассуждение: **анализ**, **выбор** или **создание**.

Подход рассчитан на reasoning / thinking-режимы ChatGPT, Claude, Gemini и других моделей. Он не заставляет модель раскрывать или имитировать цепочку рассуждений. Вместо этого помогает точнее поставить задачу: определить главный вопрос, контекст, ограничения, критерии качества и формат результата.

## Главная идея

Пользователю не нужно сразу писать большой промпт или заранее определять тип задачи.

**Тема → главный вопрос → тип задачи → конструктор → согласование блоков → готовый промпт**

Skill сначала помогает сформулировать тему и главный вопрос, затем предлагает один из трех конструкторов:

- **Анализ** — понять, объяснить, проверить, оценить.
- **Выбор** — сравнить варианты и принять решение.
- **Создание** — разработать, придумать или спроектировать новый результат.

После этого каждый блок заполняется отдельно. Пользователь редактирует или подтверждает его, и только затем skill переходит дальше. В конце согласованные блоки собираются в один промпт без новых требований и самодеятельности.

## Почему пошагово

Большой промпт, созданный за один проход, часто содержит незаметные предположения, лишние ограничения и формулировки, которые пользователь сам не выбирал.

Здесь человек остается редактором постановки задачи:

1. модель предлагает заполненный блок;
2. человек исправляет его;
3. версия фиксируется;
4. начинается следующий блок;
5. в конце собирается только то, что было согласовано.

## Три конструктора

### Анализ
Тема, вопрос и цель → Контекст и данные → Границы анализа → Критерии сильного анализа → Формат результата.

### Выбор
Вопрос выбора и цель → Контекст и данные → Ограничения и приоритеты → Критерии выбора → Формат результата.

### Создание
Что нужно создать и зачем → Контекст и материалы → Требования и ограничения → Критерии сильного решения → Формат результата.

## Как использовать

Если среда поддерживает Agent Skills, подключите папку со `SKILL.md` как skill. Затем начните с обычной формулировки задачи, например:

> Тема: использование ИИ в PR.  
> Главный вопрос: в каких задачах ИИ действительно экономит время без потери качества?

Skill сам предложит тип конструктора и начнет заполнять блоки по одному.

Если ваша среда не поддерживает skills, содержимое `SKILL.md` можно использовать как системную или стартовую инструкцию в отдельном чате.

## Примеры

В папке `examples/` находятся три коротких сценария:

- `analysis.md`
- `choice.md`
- `creation.md`

## Принцип

**Skill не заменяет пользователя при постановке задачи. Он сокращает ручную работу, но сохраняет человеческую редактуру между блоками.**
